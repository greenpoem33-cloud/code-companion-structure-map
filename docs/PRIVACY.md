# 数据与凭据

每位用户配置自己的模型服务。安装包没有附带开发者密钥或开发者登录状态。

DeepSeek 密钥通过插件页面输入，保存在本机 VS Code Secret Storage 中；不会写入项目源码。
Codex 使用用户本机已登录的 CLI。服务选择为 auto 时，按本机配置及环境选择服务；需要固定服务时可显式设置 provider。

AI 分析、问答、讲解及拟议修改会向所选模型服务发送相关问题、源码片段和必要上下文。
首次分析会读取项目结构与有限实现片段；具体数据处理取决于用户选择的服务。
聊天记录、项目分析缓存和测试记录保存在本机，不属于发布资产。
本项目不会提供公用账号、共享 API Key 或代付额度。

提交反馈时只附你有权公开的样例与截图。避免上传密钥、账号凭据、完整私人日志或私有项目源码。
