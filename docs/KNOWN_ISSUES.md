# 当前范围与已知限制

- 当前主要支持 Python 项目，Windows 已验收；macOS、Linux 尚未完成本轮验收。
- 静态扫描和单次文字讲解都有数量与上下文上限，界面会标明未展开部分。
- 反射、动态分发、第三方库内部、跨进程关系以及部分包装形式的入口可能无法解析，可手动选择起点。
- 没有下游项目调用不代表没有输出；返回去向是单独的静态使用记录，不是新增调用边。
- 测试失败保留真实退出原因，不会用失败记录补齐链路；用例通过也不等于整个业务链路已经验证。
- AI 讲解会做源码语义复核，通常增加一次模型请求；复核仍可能判断错误。
- 本轮真实模型验收使用 Codex 和专用样例项目，DeepSeek 的在线效果尚需实际用户验证。
- 当前未采集运行时参数值和返回值；经过未知调用后的容器内容可能改变。
- 修改预览中的结构提示是语法对比，不是对所有分支、数据流或运行效果的完整证明。
